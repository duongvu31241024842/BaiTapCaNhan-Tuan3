## Cấu trúc thư mục
```

├── index.html      # Trang chủ giới thiệu và liên kết đến các Lab
```

## Nội dung từng Lab
- **Lab 08:** nhúng JavaScript vào HTML (embedded, external), thẻ `noscript`, Browser Console, các đối tượng String, Date, Math.
- **Lab 09:** truy xuất và thay đổi phần tử bằng DOM, xử lý sự kiện, làm việc với form và kiểm tra dữ liệu.
- **Lab 10:** thư viện jQuery gồm selectors, sự kiện, thao tác DOM, hiệu ứng, GET request.
